# Changelog

## 1.3.0 – 2026-11-15
### New
- **Now playing**: track, artist, album art, progress and play/pause/skip when streaming over Wi-Fi or Bluetooth (in the app and the tray menu).
- **Multiple speakers**: save several pairs and switch between them from the title bar or the tray. Adding a speaker no longer replaces the current one.
- **Light theme** that follows Windows.
- **Update check**: once a day, can be turned off. Shows a banner and a tray menu item when a new version is out.
- **Copy diagnostics** and **Report a problem** in Settings → App.
- Microsoft Store (MSIX) packaging and winget manifests.
### Improved
- Faster start-up (precompiled Python files).
- The friendly model name ("LSX II LT") is shown instead of KEF's internal code.
- If adding a speaker fails, the app keeps using the current one.

## 1.2.0 – 2026-11-15
- Sound profiles (save, apply, rename, reorder, delete; tray submenu).
- Sync with this PC: on at start-up/wake, standby at sleep/shutdown; optional lock/unlock and display triggers.
- Auto-reconnect when the speakers' IP address changes.

## 1.1.0
- Windows installer (per-user, no admin), Start menu and desktop shortcuts, uninstaller.
- Tray icon in the hidden-icons area with quick controls; Start with Windows.

## 1.0.0
- First version: volume, inputs, power, all sound settings and speaker settings.
